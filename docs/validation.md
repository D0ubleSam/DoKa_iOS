# 验证记录

更新：2026-10-23。主机：Windows；没有 Xcode、iPhoneOS SDK 或连接的 iPhone 测试环境。

## 已执行

- `python -m unittest discover -s tests -v`，提供 `DOKA_SOURCE_APK`：8 项通过，未跳过。
- 真实 APK 内 24 个 LUT：每项 136 个颜色样本，共 3264 个，原 GLSL 纹理采样与转换 cube 的 CPU 插值误差不超过 `1e-12`。
- 合成 identity LUT：验证全部 262144 个格点及三轴次序，确认 PNG alpha 不影响 shader 使用的 RGB。
- 调色盘原始逐步公式与移植的矩阵公式：1729 组对照通过。
- 缺失资源、错误尺寸和 ZIP 路径逃逸输入均被拒绝。
- 18 个 Swift 文件（15 个应用源码、3 个测试源码）通过 Tree-sitter Swift 语法解析；**这不是 Swift 编译器检查，无法确认 Apple API 类型、链接或运行正确性**。
- Info.plist 和 YAML 可解析；Python 工具语法检查通过。
- `scripts/test-ios.sh` 的 Bash 和内嵌 Python 语法通过检查；XcodeGen 中的测试目标和 scheme 引用通过静态检查。
- IPA 验证器使用合成 Mach-O 测试数据检查设备/模拟器平台、签名、LUT 完整性及包结构。合成测试数据不属于可执行应用，也没有作为 IPA 交付。
- AI 代码审查修复了迟到登录覆盖注销、空归一化区域阻断像素坐标回退、换镜头时旧渲染帧重新进入构图的问题。修复尚未经过设备运行验证。
- 相机帧失效计数与编辑渲染版本分离，避免导入照片后相机停止取消编辑预览；实际导入流程仍需 iOS 验收。
- 原服务仅做过不含照片、手机号和凭据的路径检查；没有登录、查询账号权益或成功分析图片。详见 [AI 构图记录](ai-composition.md)。
